# Admin Dashboard Setup

1. Keep or create `client/.env` with:
   `VITE_API_URL=http://localhost:5000`
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `/admin/login` to sign in.
5. After login, the admin dashboard is available at `/admin/dashboard`.

The public catalog remains available at `/` and does not require administrator login.
